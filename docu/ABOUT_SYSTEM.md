1. System Overview
   The MyShop Admin Portal is an internal, web-based operations platform designed to provide platform operators with full visibility and governance over all registered Philippine MSME merchants. While store owners and cashiers interact exclusively with the MyShop mobile application, the Admin Portal serves as the centralized control tower to oversee platform health, manage subscriptions, monitor sales volume, and enforce security policies.

2. Core Objectives
   Centralized Merchant Supervision: Track individual stores from onboarding to daily operations, including branch counts, active staff, and catalog limits.

Subscription & License Governance: Manage tier allocations (Free, Micro, Small, Medium), grant trial periods, and apply manual subscription overrides for local partner merchants.

Platform-Wide Telemetry: Monitor aggregate Gross Merchandise Value (GMV), daily transaction volumes, and regional merchant density across Philippine provinces and municipalities.

Security & Session Control: Supervise active mobile terminal connections and enforce single-device session concurrency rules to protect merchant data integrity.

Direct Administrative Support: Assist store owners with account recovery, invoice import debugging, and store configuration adjustments.
